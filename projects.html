Featured Projects

1:10 Scale Self-Driving Car (AurigaBot V1)

University—Industry Relations (MCI R&D Center)

Developed a 1:10 scale self-driving car featuring CNN-based lane and object detection, recognition of 50 traffic signs, lateral and longitudinal controllers, motion model-based odometry, and autonomous parallel/cross parking.

Inventory Tracking Robot

Golrang Industrial Group

Design and implementation of a differential-drive robot for inventory tracking in supermarkets. Capable of maneuvering between shelf aisles, reading barcodes, and detecting grocery items.

Smart Home System

Bachelor’s Final Project (Supervisor: Prof. Somayeh Timarchi)

Developed a scaled-down replica of a smart home. Designed a custom PCB incorporating an ESP32, sensors, and actuators, alongside a mobile application. Primarily responsible for PCB design and embedded software programming.

Self-Balancing Robot (Simulation)

Modern Control Systems Course Project

Simulated a 2-wheeled self-balancing robot in MATLAB. Developed a controller to stabilize the robot in an upright position by dynamically adjusting motor inputs based on sensor feedback.

Ball and Beam Balancer

Industrial Control Systems Course Project

Integrated a PD-controller to balance a ping-pong ball on a plane based on data from a custom web interface. Used an ESP8266 for web communication and servo motor control.

Genetic Algorithm Image Regeneration

Introduction to Artificial Intelligence Course Project

Developed a genetic algorithm to regenerate an image from random pixels, utilizing selection, simultaneous crossover, and adaptive mutation to achieve the target image.

Robocup Rescue Line Robot

Kavosh Robotics Team

Developed a rescue robot during high school for RoboCup competitions. Contributions included embedded software programming (AVR) and PCB designing.
